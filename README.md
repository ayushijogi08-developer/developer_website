# Kunj Technologies — Official Website & Portfolio

Modern, responsive web platform and developer portfolio for **Kunj Technologies** — crafting websites and apps for local businesses.

## Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Vanilla CSS Custom Design Tokens
- **Animations:** Framer Motion + Lenis Smooth Scroll
- **Icons:** Lucide React

## Brand Configuration
The single source of truth for all brand parameters is located in `/data/config.ts` (re-exported from `src/data/config.ts`).

## Development & Build
```bash
# Run local dev server
npm run dev

# Run Oxlint
npm run lint

# Production build with automatic placeholder safeguards
npm run build
```
